## 3. 逐个核查

### 3.1 skywain/trip-planner-skill（国际行程，机制最完整）

**它能做什么**
一句话需求 → 逐小时、可核验、可预订的行程，并渲染成 8 套主题的单文件设计页（illustrated / clay / noir / glass / journal / zine / splash / portal）。SKILL.md 定义 6 个阶段（intake → brief → legs → days → assemble → 自查），配套 13 份 `references/`（data-sources、scheduling、navigation、output-template、themes 等），5 个 Python 脚本：

- `flight_scan.py` 机票日期网格比价（Google Flights，免 key）
- `route_tools.py` 地理编码 / 逐跳导航链接 / KML / ICS / 日出日落
- `render_plan.py` plan JSON → 自包含 HTML
- `plan_lint.py` 内容门禁（`--strict --asof`，还有 `examples/fixtures/bad/` 60+ 个反例夹具）
- `build_site.py` 静态站

**依赖什么**
- Python 3.9+，**标准库即可**；`fast-flights`（机票扫描）与 `Pillow`（素材流水线）为可选，缺失时降级
- 一个**浏览器工具**：酒店/OTA 实价拿不到免 key API，"browser second"（脚本优先，浏览器兜底）
- **子代理**：按城市 fan-out 并行；无子代理则串行
- 原生生图/视频能力：部分主题需要；`portal` 主题需要视频素材
- 导出探针（`themes/xprobe.sh`）**硬编码 `/Applications/Google Chrome`，仅 macOS + Chrome**

**最近更新**：2026-10-10（push）／2026-08-15 创建；49★、1 fork、MIT、846 文件、~48 MB。

**能否直接搬进 DSH**：能，但要包一层。仓库里**没有任何 DSH 适配**（README 全篇未提 DSH/DeepSeek Harness，安装路径是 `~/.claude/skills/trip-planner`）。要么放进 DSH 的 skills 根目录，要么照 `dsh-trip-planner-cn` 的 `index.js` 写一个 20 行的 `registerProvider` 壳子。

**优点**
1. 核验纪律是所有候选里最硬的：价格/营业时间必须带来源 + as-of 日期，查不到就写"—, check link"，且用 `plan_lint` 机器校验（含 60+ 反例）
2. 交付质量最高：8 套主题、4 个可点开的线上示例、KML/ICS/地图逐跳链接
3. 纯 MIT，脚本标准库为主，无 key 也能跑（机票退化为深链）
4. 仍在维护（2026-10-10 有推送）

**缺点**
1. **不含境内链路**：没有 12306、没有高德/百度深链，境内行程用它会"水土不服"
2. **本机缺 Chrome**：导出探针与部分截图能力直接不可用；酒店实价也依赖浏览器
3. 体量大（48 MB、846 文件）、SKILL.md 33 KB + 13 份 references，**上下文开销高**
4. 需要子代理并行才跑得顺（按城市 fan-out）

### 3.2 dsh-trip-planner-cn（境内版，DSH 原生）

**它能做什么**
`trip-planner-cn` skill：把"我想去某地玩 N 天"变成逐小时、逐项可预订的境内行程 —— 城际交通（12306 / 携程 / 去哪儿 / Trip.com 深链）、每日时间线（营业时间、停留时长、调休冲突、高德/百度逐跳导航 + 离线 KML）、按街区住宿、人民币预算、带深链的预订清单，最后渲染成 7 套主题页（插画/黏土/夜航/玻璃/手账/Zine/闪屏）。四种工作模式：整趟旅行 / 单日 / 空档填充（"我在 X 附近有 2 小时"）/ 临场重排。

**依赖什么**（全部**可选**，不配 key 也能完整规划 + 渲染，只是降级）

| 变量 | 作用 | 缺失行为 |
|---|---|---|
| `AMAP_KEY` | 高德 Web 服务 key | 静态地图隐藏，时距用估算 |
| `BAIDU_MAP_AK` | 百度地理编码回退 | 跳过回退 |
| `DASHSCOPE_API_KEY` / `SILICONFLOW_API_KEY` | 境内生图 | 图片走内置素材库或模型原生能力 |
| `TRIP_MAP_PROVIDER` | `amap`（默认）/ `baidu` | 默认高德 |

代码侧：**Python 3.9+ 纯标准库**（我逐文件核过 import：`argparse/json/math/os/re/sys/time/urllib/pathlib/unicodedata/zoneinfo/hashlib`，无第三方）；Pillow 仅在素材流水线可选。**不需要 Node、不需要浏览器、不需要常驻服务。**

**最近更新**：npm 0.1.2 发布于 2026-10-17（首发 2026-10-10，共 3 个版本）；月下载 **1,677**；GitHub 上游 8★、MIT、2026-10-19 推送。

**能否直接搬进 DSH**：**这就是为 DSH 做的**。`package.json` 带 `dsh.bundle.patch → ./cordis.patch.yml`，`index.js` 用 `ctx.skills.registerProvider()` 注册技能（`inject = ["skills"]`），peer 声明 `@deepseek-ai/dsh-skill` 三个兼容区间；本机插件市场索引已收录 0.1.2。安装即 `dsh plugin --profile <p> add dsh-trip-planner-cn`（本任务不装）。

**优点**
1. **零 key 可跑**，境内数据源全部免密钥或深链兜底，最贴合"查攻略"场景
2. 纯标准库 → 不吃 Python 环境，不装 pip 包
3. DSH 原生注册，装完技能目录直接出现 `trip-planner-cn`
4. 有内容门禁 `plan_lint.py --strict`（渲染前卡住缺字段/日期不一致/坐标错误）
5. 内置 ~50 张 stock 图（webp），断网也能出主题页

**缺点**
1. **硬边界：只做中国大陆境内，港澳台也停止**（SKILL.md 明确写"目的地为港澳台时同样停止"）
2. 上游只有 **8★、单人维护**（cccccym），npm 三个版本都在 10 月，长期维护存疑
3. 高德是"可选"，但不配 key 就没有真实时距/静态地图，质量明显掉档
4. 素材库以国际地标为主（acropolis、angkor-wat、big-ben…），**境内景点匹配度一般**，容易落到通用图
5. 文档很长（SKILL.md 23 KB + `output-template.md` 35 KB + `themes.md` 40 KB）

### 3.3 bcefghj/skills-collection · travel-skill（是"生成器"，不是规划引擎）

**它能做什么**
`/create-trip`：问 5 个问题（目的地、时间、天数、风格、特殊需求）→ 导入小红书/马蜂窝/携程攻略、地图收藏、预订邮件 → 生成一套属于你的 `trips/{slug}/`（itinerary.md + persona.md + budget.md + meta.json + 可调用的 SKILL.md），支持"我不想去这里"式实时改、版本回滚、`/list-trips`。**核心卖点是"旅行人设"（5 层偏好结构）+ 增量合并**，而**不是**核实价格/营业时间。

**依赖什么**：Python `requests>=2.28.0`、`pypinyin>=0.48.0`（`requirements.txt`）；工具链全部用 `${CLAUDE_SKILL_DIR}` 解析，安装路径写死 `.claude/skills`、`~/.cursor/skills-cursor`、`~/.openclaw/...`，命令是 Claude Code 的 slash 命令，`allowed-tools: Read, Write, Edit, Bash`。

**最近更新**：**2026-04-01 创建，同日最后推送 —— 之后 7 个月零提交**。25★、无 LICENSE 文件、343 文件（20 个生活场景 skill 的合集）。

**能否直接搬进 DSH**：不能直接用。slash 命令与 `${CLAUDE_SKILL_DIR}` 语义在 DSH 下不成立，得重写调用约定；`Bash → python3` 的相对路径也要改。

**硬伤（这是判"别用"的直接依据）**
1. README 的安装命令是 `git clone https://github.com/bcefghj/travel-skill`，**该仓库不存在（API 返回 404）**，真实代码只在合集子目录里 → 照文档装必然失败
2. **无 license**：默认保留所有权利，不能合法搬进产品
3. 7 个月未更新，且没有任何"价格/时间核验"机制 —— 它产出的是"像模像样的行程文本"，不是可核验行程
4. 纯 Claude Code 绑定

**唯一值得抄的**：Part B 的"旅行人设"五层结构（硬性规则 → 身份 → 节奏 → 消费 → 偏好矩阵）与"增量合并不覆盖已有安排"的更新策略 —— 这两点对"越用越懂你"很有用。

### 3.4 zexuanw958-svg/travel-plan-viz（自搜补充，最热）

**它能做什么**：把行程变成**单文件、离线可读、手机优先**的 HTML：Leaflet 交互地图 + 每日时间轴 + 出发前订票提醒（`computeReminders`/`leadDays`）+ 校验器。两种模式：只给目的地天数（模式 A 从零规划）／丢一份现成计划（模式 B 解析重排）。数据与呈现分离（`<script id="trip-data">` 内嵌 JSON），后续"把第三天 X 挪到第四天"可直接改 JSON 重渲染。

**依赖什么**：无 key。Node 跑 `assets/validate.js` 做机械校验；地图用 **Leaflet CDN**（首次打开需联网）；设计步骤优先调用已装的 `frontend-design` / `huashu-design` skill，没有就用内置准则兜底。若当前 Agent 已装飞猪/高德/腾讯地图/滴滴的官方 skill 或 MCP，会**优先复用**拿实时数据——**它自己明确声明"不查实时票价"**。

**最近更新**：**2026-11-08 推送（就在昨天）**，412★、16 fork、MIT、25 文件，是这个赛道里最活跃的。

**能否直接搬进 DSH**：能，最省事的一个 —— 纯 SKILL.md + assets，把 `travel-plan-viz/` 放进 skills 目录即可。

**优点**：最热、最新、零依赖、自带校验器、单文件 HTML 正好是"能双击打开给家人看"的交付形态、有成都/香港/深圳/东京 4 个真实样例。
**缺点**：**它不做调研与核验**（实时票价不查、数据准确性不背书），本质是"渲染 + 体检"层；设计质量取决于有没有装设计 skill；地图瓦片仍需联网。

> 结论：**与 3.1/3.2 是互补关系，不是替代关系** —— 用 3.2 做"核验与规划"，用 3.4 做"页面与体检"。

### 3.5 Tulip-557/verified-travel-planner（自搜补充，方法论最值得抄）

**它能做什么**：中文境内"可核验路书"。核心是两套机制：
- **证据分级 A/B/C/D**：`[A] 工具实证`（地图 API / 12306 余票 / 官方票价）才能当硬事实，`[B] 多源交叉` 可进正文，`[C] 单源` 只能进备选池，`[D]` 如实写"未核实"。票价/车次/营业时间**只能取 A**，UGC 一律不作为来源
- **机械自查 30 项**：交付前跑脚本硬校验，而不是靠提示词祈祷

产物：JSON 事实源（唯一事实源）+ 单文件 HTML 路书 + 美食情报卡；另有"社会情报采集"（官方文旅发布/搜索索引/用户投喂，跨行程复用）。

**依赖什么**：Python 引擎 `engine/travel_planner/`（`amap.py`、`rail.py`、`flight.py`、`weather.py`、`lodging.py`、`geomatch.py`、`feasibility.py`、`credentials.py`）→ **需高德 key**；references 里有 `browser-use.md`（浏览器自动化）。

**最近更新**：2026-10-25 推送，1★、2 fork、MIT、152 文件、Python。

**能否直接搬进 DSH**：中等。引擎是独立 Python 包，理论上可当工具层；但 SKILL.md 45 KB，且大量依赖 browser-use 与高德 key。

**优点**：证据分级 + 双写一致性（改决策必须回写 JSON）+ 30 项机械自查，是**所有候选里最工程化的一套"防 AI 编数字"设计**；README 坦白说明自己融合了 `tanweiping1012/travel-planner`（实证派）与 `awangwang123/jianhao-travel-planner`（校验派）。
**缺点**：1★ 单人项目，2026-09-30 才建，未经大规模验证；必须配高德 key；体量与复杂度都偏高。

### 3.6 joshgoncsu/ai-trip-planner-skill（自搜补充，纯方法论）

**它能做什么**：家庭/团体游的"决策流程"skill —— 群体校准（年龄/体力/预算/兴趣）、选项菜单（带链接让用户选）、行程压力测试（`CHALLENGE` 步骤主动挑战不现实安排）、**决策锁定**（AGREED/LOCKED 记录）、Master Trip Plan + 一页可视化行程（发群里用）、行后复盘。流程：`ASK → OFFER OPTIONS → USER CHOOSES → DRAFT → CHALLENGE → REVISE → LOCK → DOCUMENT`。

**依赖什么**：**零**。15 个文件全是 Markdown（SKILL.md + 8 个 templates + 2 个完整示例 + CHANGELOG/ROADMAP），不联网也行（联网是为了查资料）。

**最近更新**：2026-10-26 推送，**0★**、MIT、2026-10-04 创建。

**能否直接搬进 DSH**：极高，直接放进 skills 目录即用，无任何运行时依赖。

**优点**：多人/带娃/带老人场景的**方法论最扎实**（"每轮最多 4 个问题"、"只问会改变计划的事"、"决策锁定不反复"），零依赖、体积小、可读性好。
**缺点**：**没有任何工具/脚本**，不做价格核验，全凭模型知识；0★ 无社区验证；英文。

> 结论：不单独用于交付，但**"群体校准 + 决策锁定 + 压力测试"这三段可以整段搬进我们自己的 SKILL.md**。

### 3.7 dsh-travel-planner（DSH Agent Preset，最重）

**它是什么**
不是 skill，是 **Agent Preset**：`dsh.bundle.patch → preset/cordis.patch.yml`（24 KB），外加 2 个运行时插件（`travel-env.mjs` 自举环境、`travel-finance.mjs`）、1 份 `persona.txt`（14 KB 独立人设）、9 个技能（`travel-planning`、`travel-roadbook`、`travel-maps`、`travel-hotels`、`travel-transport`、`travel-constraints`、`train-booking`、`flyai-cli`、`amap-cli-skill`）、`vendor/12306-mcp`（带预售期补丁）。装完新建会话要**在模式里选「旅行规划师」**。

**依赖什么**（这是关键 —— 明显重于其他候选）

| 类别 | 要求 |
|---|---|
| Key（**必需**） | `AMAP_KEY` + `AMAP_SECURITY_KEY`（高德 **Web端 JS API**）、`FLYAI_API_KEY`（飞猪，实名认证） |
| Key（可选） | `GOOGLE_MAPS_API_KEY`（路书里的可拖动地图）、`UNSPLASH_ACCESS_KEY`（配图）、途牛（走 `tuniu auth login` 网页授权） |
| 全局 CLI（`npm install -g`） | `@fly-ai/flyai-cli`（必需）、`@amap-lbs/amap-gui`（必需）、`tuniu-cli`（推荐） |
| Python | ≥3.9 + **Pillow**（地图底图、静态检查） |
| 浏览器 | **Chrome 或 Edge**（无头：高德真实路线、截图、布局检查），`CHROME_PATH` 可配 |
| 其他 | 12306 MCP **从 GitHub 拉源码编译（1–3 分钟）**；Git；Node ≥22 |
| 安装位置 | 写 `~/.dsh/preset-assets/travel-planner/`（工具脚本 + `.env`）、`~/.dsh/skills/`（9 个技能）、`~/.dsh/tools/12306-mcp`，并**注册 bundle 到 profile**，装完需完全退出重启 |

**最近更新**：npm 1.0.0 发布于 2026-10-03（此后无新版本，已 5 周）；月下载 **843**；GitHub MIT。

**能否直接搬进 DSH**：它本来就是 DSH 的，但**代价最大**：改 profile、写 `~/.dsh` 三处目录、全局装 3 个 CLI、编译 MCP、重启、替换人设为「旅行规划师」。在我们的沙箱（workspace-write、禁止装全局软件、审批全关）下**装不了也不该装**。

**优点**：唯一"全链路真数据"的候选（飞猪实时票价 + 高德真路线 + 12306 余票），交付的单文件 HTML 路书质量高，文档（INSTALL/KEYS/DEVELOPMENT）非常完整，作者还带 CI 与 doctor 自检。
**缺点**：重；**必需两套 key**；强绑飞猪/高德/途牛 CLI；要 Chrome/Edge 无头；是"换 agent"而非"加技能"，会挤掉现有工作流；版本停在 1.0.0。

### 3.8 tripo-dsh（顺带核查：与旅游无关）

**它是什么**：Tripo（tripo3d.ai）的 3D 资产生成技能包，注册 2 个技能：`tripo-3d`（文/图/网格 → 带贴图、可绑骨的 3D 模型，导出 GLB/FBX/OBJ/STL/USDZ/3MF）、`tripo-game-asset`。走 `npx tripo-cli`（≥0.7.0），需要 Tripo 账号（新号送额度）、消耗 credits，支持国内/国际两个区域。2026-10-20 发布 0.1.4，月下载 1,631，7 个文件。

**结论**：**与旅游攻略无关**，是 3D/游戏资产方向。若后续要做"行程页里的 3D 元素"才可能沾边，否则不要装（多一个消耗额度的外部服务）。

> 注意：本会话是 workspace-write 沙箱且**审批全关**，我**没有安装**任何包。上述"直接用"指"用户/lead 授权后，在正常环境执行 `dsh plugin add` 即可"，不是我已装好。

### 4.2 改造后用（抄机制或包一层，不建议整包塞入）

| 候选 | 怎么改 | 抄什么 |
|---|---|---|
| `skywain/trip-planner-skill` | ①照 `dsh-trip-planner-cn/index.js` 写 `registerProvider` 壳；②把 Chrome 依赖换成 Edge（`CHROME_PATH`）或直接删掉导出探针 | **核验纪律**（每个数字带来源+as-of）、`plan_lint` + 60 个 `fixtures/bad` 反例、`references/` 分阶段文档结构 |
| `verified-travel-planner` | 只搬"证据分级 + 机械自查"两段进自研 SKILL.md，不装它的 Python 引擎 | **A/B/C/D 证据分级**、单一事实源 JSON + 双写一致性、30 项交付前自查 |

### 4.3 别用

| 候选 | 不用的硬理由 |
|---|---|
| `dsh-travel-planner` | ①**必需**两套 key（高德 JS API + 飞猪实名）；②要 `npm i -g` 三个 CLI —— 违反"禁止安装全局软件"；③要写 `~/.dsh` 三处目录 + 改 profile + 重启 —— 超出 workspace-write 沙箱；④是 Preset，会**替换 agent 人设**而非叠加技能；⑤停在 1.0.0 五周未更新。**除非用户明确愿意按 INSTALL 全量配置，否则不要碰。** |
| `bcefghj/skills-collection · travel-skill` | ①**没有 LICENSE**（法律上不可搬）；②README 的安装源 `bcefghj/travel-skill` **404**；③**7 个月零提交**；④绑定 Claude Code 的 `${CLAUDE_SKILL_DIR}`/slash 命令；⑤本身不做价格/时间核验。只能当"人设蒸馏"的灵感来源，**不能当引擎、不能当代码来源**。 |
| `tripo-dsh` | 与旅游无关（3D 资产生成），且引入需付费额度的外部账号，纯属增加攻击面。 |

### 4.4 对我们这个项目的建议（如果目标是产出攻略文件）

1. **别急着装插件。** 先在 `模板/` 里落一个自研 SKILL 骨架，把三样东西固定下来：
   - 交付物 = **单文件 HTML 路书 + 一份 plan JSON 事实源**（渲染与数据分离，改行程只改 JSON）
   - 每一行价格/时间必须写 **来源 + 查询时戳**，查不到写"未核实·点链接确认"（抄 3.1/3.5）
   - 交付前跑一次**机械自查**（字段完整性、日期一致性、坐标越界、相邻点是否有路线）
2. **验证器优先于提示词。** 3.1 的 `plan_lint` + 60 个 bad fixtures、3.5 的 30 项自查、3.4 的 `validate.js`，都说明同一件事：**靠脚本卡，不靠模型自觉**。
3. **境内用 3.2 的数据源清单**：高德/百度（坐标、时距、POI）、12306/携程/去哪儿/Trip.com（深链）、timor.tech + 国务院放假安排（调休）、Open-Meteo/中央气象台（天气）、本地天文模型（日出日落，零网络）。
4. **若必须二选一装一个**：选 `dsh-trip-planner-cn`（轻、零 key、DSH 原生）；**不要**选 `dsh-travel-planner`（重、要 key、要全局 CLI）。
