# 路线与地图：高德

> 结论来自 2026-11-09 本机实测，详见 `research/03-高德地图路线.md`。原则：**能不用 Key 就不用 Key。**

## 三种交付物

| 交付物 | 用什么 | 要 Key |
|---|---|---|
| 攻略里那张路线示意图（SVG/PNG） | `scripts/amap_route.py` 本地自绘 | ❌ |
| "点这里导航到下一站" | `uri.amap.com/navigation` 深链 | ❌ |
| PC 上看完整路线 | `ditu.amap.com/dir?...` | ❌ |
| 真实驾车/公交耗时、里程 | `amap_route.py --live`（OSRM，OSM 路网） | ❌ |
| POI 搜索、天气、专属地图 | 高德 Web 服务 API / 官方 MCP | ✅ |

## 无 Key 主力：自绘路线图

```bash
python3 .dsh/skills/travel-guide/scripts/amap_route.py \
  --out 路线图.svg --html 路线图.html --links 链接.json --title "成都 4 日"
```

- 输入来自脚本内置样例；真实行程用 `--from-json points.json`，格式 `[{"name":"宽窄巷子","lng":104.06,"lat":30.66}, ...]`。
- 若坐标是 GPS 原始值（WGS-84），加 `--from-wgs84` 自动转 GCJ-02。
- 输出：SVG 静态图、可点的 HTML、逐段 URI 链接 JSON。
- 纯标准库，不联网、不装包。

## 无 Key 也算真实里程：`--live`

```bash
python3 .dsh/skills/travel-guide/scripts/amap_route.py \
  --from-json 路线点位.json --out 路线图.svg --html 路线图.html --mode walk --live
```

- 走 OSRM 公共路由（`router.project-osrm.org`，OpenStreetMap 路网），把直线距离换成**真实路程**，
  驾车模式还能拿到 OSRM 返回的**真实耗时**；步行/骑行/公交的路程同样来自路网，时间按平均速度估算（会带"约"字）。
- 关键：请求前会把 **GCJ-02 转回 WGS-84**，否则整条线偏 500 米。
- 失败自动回落到直线距离，不会中断出图。
- 实测（成都 4 点步行线）：直线 4.7 km → OSRM 实际 6.2 km，约 1 小时 23 分。
- 注意：OSM 在中国大陆的路网密度不如高德，郊区/景区内部可能绕远；**要写进正文的数字仍以高德为准**。

## 官方 MCP（有 Key 时可用）

高德官方 MCP：<https://developer.amap.com/api/mcp-server/summary>，本质是"你的 Key + Web 服务"。

- Streamable HTTP（本机可用）：`https://mcp.amap.com/mcp?key=<你的KEY>`
- Node I/O：`npx -y @amap/amap-maps-mcp-server`（本机无 npx，不可用）
- 实测端点活着：不带 Key 请求 `https://mcp.amap.com/mcp` 返回 `{"status":"0","info":"INVALID_USER_KEY","infocode":"10001"}`。
- 11 项能力：专属地图、导航、打车、地理/逆地理编码、IP 定位、天气、骑行/步行/驾车/公交路径规划。
- **「生成专属地图」是 MCP 独有的**：能把整份行程导入高德 App 变成私有地图，做"一键导入"时才值得上。

## 有 Key 时（提升精度）

```bash
python3 scripts/amap_route.py --check-key   # 只校验，不打印明文
```

Key 读取顺序：`AMAP_MAPS_API_KEY` 环境变量 → `~/.dsh/amap/credentials.json` → `~/.dsh/amap/key`。

**Key 不要写进工作区**（会同步/进 git/被截图）。申请需**个人实名认证**；免费额度只有 1 年，基础 LBS 15 万次/月，搜索与天气各 5000 次/月，超量 30 元/万次。

## 坐标系（最容易翻车）

| 坐标系 | 谁在用 |
|---|---|
| WGS-84 | GPS、国际数据、大多数开放数据 |
| GCJ-02 | 高德、腾讯、国内绝大多数地图（火星座标） |
| BD-09 | 百度 |

同一个天安门，WGS-84 与 GCJ-02 差 **555 米**。从别处抓来的坐标先问清楚是哪套；高德一律要 GCJ-02。转换函数已在 `amap_route.py` 与 trip-planner-cn 的 `scripts/route_tools.py` 里。

## 链接行为（实测）

- `uri.amap.com` 单点/多点标注、导航链接均返回 200。
- 移动 UA 会 302 到 `m.amap.com/navigation/...`（公交/步行/骑行分别落 buslist/walkmap/ridemap），桌面 UA 落 `ditu.amap.com/dir?...`。
- **微信/QQ 内置浏览器能打开 H5，但唤不起高德 App**（官方明确 `callnative` 在微信 QQ 内不可用）。所以分享文案里不要写"点开直接跳到高德 App"。

## 与 trip-planner-cn 的分工

- 它自带 `route_tools.py`：POI 检索、逐跳导航链接、离线 KML、日出日落、里程重算。
- 本脚本只负责"一张好看的图"，两者可以一起用：trip-planner-cn 出计划与链接，amap_route.py 出图。
