# 取材：小红书 / 抖音 / 官方渠道

> 结论来自 2026-11-09 本机实测，详见 `research/02-小红书抖音取材.md`。

## 一句话

- **抖音**：抓 `/shipin/<id>` 落地页，零依赖、匿名可用，一次能拿到 10+ 条相关攻略的 ASR 转写。
- **小红书**：**零登录抓不到**（HTTP 200 但正文为空壳，别被状态码骗了）。走"用户登录后人工粘贴/截图"。
- **票价、开放时间、预约规则**：一律不以 UGC 为准，用官方/高德二次核验。

## A. 抖音（默认自动）

```bash
PY=.dsh/skills/travel-guide/scripts/douyin_pick.py
python3 $PY 7373860356739090473 -o 素材/douyin.json --md 素材/douyin.md
```

- 输入可以是 `https://www.douyin.com/shipin/<id>`、`/video/<id>` 或纯数字 id。
- 发现 id 的办法：`web_search("成都 三日游 攻略 site:douyin.com")`，或直接搜"<目的地> 旅游攻略 抖音"。
- 一次抓 3–8 个视频，间隔 ≥3 秒（脚本默认已 sleep）。不建库、不长期缓存全文。
- 输出里每条都带 `title / duration / transcript`；转写是 ASR，**引用时必须注明"语音识别，可能有误"**。
- 页面结构变了脚本会报"页面过小"或 0 条，**看到 0 条就当失败**，不要凭空补。

## B. 小红书（已配置：xiaohongshu-mcp，扫码一次）

小红书正文由 `x-s / x-t` 签名接口加载，匿名 HTTP 拿到的永远是同一张"页面不见了"空壳（约 97 KB，标题一致）。**所以必须走登录态。** 本工作区已装好 `xiaohongshu-mcp`，走的是"替你操作已登录浏览器"，不是 cookie 外泄。

### 一次性启动（服务没起时才做）

```bash
工具/xhs-mcp/start.sh          # 起服务，127.0.0.1:18060
```

没登录过时才需要 `工具/xhs-mcp/login.sh` 扫码。登录态在 `工具/xhs-mcp/cookies.json`（600 权限），浏览器在 `.home/`。

### 取材

```bash
PY=.dsh/skills/travel-guide/scripts/xhs_pick.py
python3 $PY --keyword "成都三日游" --limit 3 --comments \
  -o 素材/xhs.json --md 素材/xhs.md
```

- 关键词可重复：`--keyword "成都三日游" --keyword "成都避坑"`。
- `--comments` 会连评论一起抓——**避坑点基本都在评论里**（实测："人民公园采耳死贵""想累死就照着这个攻略玩"）。
- 输出每条带：标题 / 作者 / 点赞收藏评论数 / 发布时间 / 原文链接（含 xsec_token）/ 正文 / 评论摘录。
- 一条笔记约 10–30 秒（要滚动加载评论），3 篇大约 1–2 分钟，别设短超时。

### 边界

只读；单次 ≤10 篇；篇间 ≥3 秒；不建库、不存全文；**不点赞、不评论、不关注、不发帖**（MCP 有这些工具，不用）。
小红书 `robots.txt` 对 `*` 全站 Disallow，这属于"平台不欢迎"的范畴，自己承担风险、低频使用。

### 兜底：人工复制

服务挂了/没登录时，让用户在浏览器里打开笔记复制正文粘贴进来，效果一样，只是慢。

## C. 官方与地图（P0 事实源）

| 字段 | 去哪查 |
|---|---|
| 坐标、POI、步行/驾车耗时 | 高德（见 `路线与地图.md`） |
| 开放时间、闭馆日、预约 | 景区官网/官方公众号/文旅局 |
| 门票、优惠政策 | 官方购票页 / OTA |
| 高铁/航班时刻 | 12306 / 航司官网 |
| 天气 | 中央气象台 / Open-Meteo |
| 放假调休 | 国务院办公厅当年安排 |

## 取材字段清单（决定一条攻略有没有用）

**P0 硬信息**（错一个就翻车，必须官方核验）

- 准确名称 + 所在区 + 坐标
- 开放时间 / 闭馆日 / 是否要预约实名
- 票价 + 优惠 + 购票渠道
- 交通方式与耗时（地铁几号线哪站、末班车）

**P1 体验信息**（UGC 的真正价值，多篇交叉）

- 排队与人流时段（"7 点前到""11 点后熊猫睡觉"）
- 避坑点（网红店踩雷、景区溢价、假门票、强制消费）
- 人均消费（吃/住/门票分项）
- 住宿区域 + 价格带 + 离地铁距离

**P2 加分项**

- 季节/花期/雨季/温差
- 体力强度（步行距离、爬坡、索道）
- 拍照机位与出片时间

## 合规红线

1. 不批量爬取、不跨账号、不用代理池、不绕过登录墙。
2. 不碰用户 cookie / 密码 / 扫码凭证。
3. 引用而非全文搬运；成品里写"素材来源 + 链接"。
4. 小红书 robots 全站禁止 → 任何自动化都属平台不欢迎行为，只做人工低频。
5. 抖音 `/shipin/` robots 允许，但仍"只抓当前需要的几页、保留出处"。
