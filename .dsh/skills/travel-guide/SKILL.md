# travel-guide：从"想去"到"能发群里"

这个技能是**入口**。它不重复造规划引擎：境内行程的骨架、核验纪律、plan.geo.json
与七套主题渲染都在 `trip-planner-cn` 技能里，本技能负责**取材、偏好、路线图、分享**
这四件它不做的事，并把整条链路串起来。

## 0. 先读偏好

读 `偏好/我的偏好.md`。缺的关键项**一次问清，最多 4 个问题**：

1. 从哪出发、大概什么时候、几天
2. 几个人、有没有老人小孩
3. 预算档位
4. 必须去 / 必须不去

判据：只问"答案会改变行程"的事；能自己查的（天气、门票）不要问用户。

## 1. 分流

| 目的地 | 怎么做 |
|---|---|
| 中国大陆境内 | 加载 `trip-planner-cn`，按它的 phase-0/1/3/4/6 走；本技能补取材、路线图、分享 |
| 境外 / 港澳台 | `trip-planner-cn` 明确不支持。仍用本技能流程，但内核手写，并**明确告知用户**境外部分未做官方核验 |

## 2. 取材（三条腿，缺一不可）

1. **平台经验**：抖音用 `scripts/douyin_pick.py` 自动抓；小红书用 `scripts/xhs_pick.py`
   （走本地已登录的 `工具/xhs-mcp` 服务，服务没起先跑 `工具/xhs-mcp/start.sh`）。
2. **官方事实**：开放时间、票价、预约规则、交通接驳。
3. **地图**：坐标、距离、耗时。

产出 `素材/取材.md`，每条素材记：平台 / 标题 / 链接 / 发布时间 / 采纳了什么 / 可信度。

> 详细规则（含实测证据、合规红线、字段清单）见 `references/取材.md`。

## 3. 证据分级（防"AI 编数字"）

| 级别 | 含义 | 能写进正文吗 |
|---|---|---|
| A | 工具实证（地图 API、12306、官方票价页） | ✅ 当硬事实 |
| B | 多源交叉一致 | ✅ |
| C | 单源 UGC | ⚠️ 只能进"备选 / 听说" |
| D | 未核实 | ❌ 明写"未核实，点链接确认" |

**票价与开放时间只能 A。** 模型记忆可以负责"哪里值得去"，不能负责"多少钱、几点关门"。

## 4. 排行程

骨架规则用 `trip-planner-cn` 的；本技能额外补三条：

- **地理聚类**：同一天的点尽量落在同一 3 km 半径内；跨区一天最多一次。
- **强度守恒**：日均步行不超过偏好上限；带老人小孩每天最多 2 个主景点。
- **每天一个 Plan B**：下雨 / 排队超 40 分钟 / 临时闭馆时换什么。

## 5. 路线与地图

```bash
python3 .dsh/skills/travel-guide/scripts/amap_route.py \
  --out 路线图.svg --html 路线图.html --links 链接.json --title "成都 4 日"
```

默认**不用高德 Key**：URI 深链 + 本地自绘 SVG 覆盖"能看、能导航、能发微信"。
加 `--live` 可走 OSRM 拿到真实路程与驾车耗时（实测 4.7 km 直线 → 6.2 km 实际）。
只有 POI 搜索、天气、专属地图这类才需要高德 Key。详见 `references/路线与地图.md`。

## 6. 出成品

目录：`行程/YYYY-MM-DD-目的地/`

```
行程.md          # 主文档，套 模板/行程模板.md
路线图.svg       # 可直接发群
路线图.html      # 可点的交互版
分享长图.png     # 微信/QQ 直发
分享文案.md      # 配图文字
素材/            # 取材记录、引用链接
```

交付前跑机械自查（不要靠模型自觉）：

```bash
python3 .dsh/skills/trip-planner-cn/scripts/plan_lint.py plan.geo.json --strict
```

## 7. 分享

生成长图 + 文案，写进剪贴板并唤起 App，由用户选人粘贴发送：

```bash
python3 .dsh/skills/travel-guide/scripts/share_card.py 分享卡片.json \
  -o 攻略长图.png --copy --open wechat
```

当前会话若有 `send_wechat` 工具，可直接推送到微信（受 24 小时会话窗口限制）。
细节与"不要做"的清单见 `references/分享.md`。

## 8. 落盘

1. 在 `索引.md` 的行程表追加一行（日期 / 目的地 / 天数 / 状态 / 路径）。
2. 这次暴露出的偏好，回写 `偏好/我的偏好.md`（例如"原来不爱爬山"）。
3. 素材链接留在 `素材/`，不要只留在对话里。

## 常见坑

- **小红书返回 200 不等于成功**：匿名抓正文是空壳，要按字数判断；走 `xhs_pick.py`。
- **xhs_pick 很慢**：一篇 10–30 秒（要滚评论），3 篇 1–2 分钟，别设 90 秒就断。
- **高德坐标是 GCJ-02**：从 GPS 或国外数据拿到的坐标先转换，否则偏 500 多米。
- **微信里唤不起高德 App**：只能开 H5，别在文案里承诺"点开直接跳转导航"。
- **抖音 ASR 有错别字**（"贡达雪山"实为"贡嘎"），引用前人工过一遍。
- **时效**：天气、花期、演出时刻表出发前 3 天必须复查；UGC 只看近 18 个月。
