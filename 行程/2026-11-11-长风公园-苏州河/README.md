# 长风公园 · 苏州河 夜游（2026-11-11 周三）

**一句话**：19:50 在 15 号线「长风公园」站站厅碰头 → 20:00 进公园看灯（西老河—银锄湖—枕流桥—铁臂山）→ 出园上大渡河路桥 → 沿苏州河北岸走到丹巴路码头 → 21:30 关灯前收尾 → 打车 5 分钟去长风大悦城或夜宵。

- 步行约 3.2 km，20:00—22:00，两人
- 天气：晴，20:00 约 13℃、体感 12.6℃，无雨；江边带外套
- 硬约束：景观灯 **21:30 关**；公园**南区施工只走北区**

## 两个出发点

- A：**15 号线武威东路站** → 5 站到长风公园，约 12 分钟。
- B：**2 号线北新泾站** 2 站 → 娄山关路换 **15 号线** 1 站 → 长风公园，约 25—30 分钟。
- 出站走 **2 号口**（去公园）/ **3 号口**（去大悦城）。
